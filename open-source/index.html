Where I want to contribute

I’m interested in open-source development around Go, Kubernetes, cloud-native infrastructure, developer platforms and agent tooling. I want to contribute through code, reproducible bug reports, fixes, design reviews and documentation that makes a system easier to understand and operate.

Useful collaboration connects a change to a clear problem and a way to verify the result. Architecture overviews, setup instructions, API examples and scope notes are part of that work because they help another developer decide where to begin.

My GitHub profile links to public activity. For a specific project, start with its repository README and contribution guidance, then check current issues and implemented behavior.
